# docs

This folder contains the documentation for the MIA project.

## MIA Manual

The `MIAManual.tex` file is the source for the MIA manual, which covers commands, features, and usage.
`MIAManual.pdf` and `MIAManual.idx` are the built PDF and its index, generated from the `.tex` source.

## TeX_files

The `TeX_files/` folder holds the LaTeX fragments included by `MIAManual.tex`, broken out by topic (e.g., `MIAcommands.tex`, `MIAConfig.tex`, `CodingStandards.tex`, `Utilities.tex`, `Libraries.tex`, etc), plus shared `packages.tex` and `settings.tex`.
Edit these fragments to update the manual; rebuild the PDF from `MIAManual.tex`.

## images

The `images/` folder holds the figures and diagrams referenced by the manual.
