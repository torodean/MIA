\section{Systems Development}

The MissionCraft game will consist of various interconnected systems all working in tandem. Often times, when developing a large project like this, the development of the systems can begin to get complicated and the project can begin to become overwhelming. In order to alleviate some of that, the various systems can be developed and tested independently - then connected afterwards. The systems will need to be designed with this in mind.
